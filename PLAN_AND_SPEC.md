# Technical Specification & Integration Plan for Subtelne Detale Sewing Kit Constructor
> **Проект:** Интерактивный конструктор комплектов пошива (ткани, кружево и фурнитура для нижнего белья)
> **Клиентский сайт:** [subtelnedetale.pl](https://subtelnedetale.pl/)
> **Стек сайта-получателя:** Laravel (PHP) + Python 
> **Статус решения:** Разработан и полностью укомплектован готовый интерактивный MVP-прототип (React + Tailwind CSS + Vite + Node/Gemini API).

---

## 1. Концепция продукта (User Flow)
Уникальный опыт индивидуального подбора материалов для пошива деликатного белья дома:
1. **Начало работы**: Пользователь заходит на страницу конструктора. Он видит элегантный тонкий векторный чертеж деталей бюстгальтера (с разметкой на лекала: чашечки, пояс, бретели, туннельные ленты, фурнитура).
2. **Интерактивный чертеж**: Клиент может нажать на любую детальку чертежа. Выбранная область подсвечивается золотым обрамлением. Справа открываются соответствующие товары со склада.
3. **Безумный цветной микс (Вариант Б)**: Свободный выбор любых артикулов из каталога. При назначении товара деталь на чертеже моментально закрашивается в точный цвет товара (*Hex-код*) с наложением полупрозрачной кружевной упругой текстуры. Трендовый статус гармонии указывает, насколько цвета согласуются.
4. **Готовые палитры**: Возможность мгновенно применить готовые технологические наборы (например, *Изумрудный шик*, *Винный вечер*), чтобы не собирать детали по одной.
5. **Творческий ИИ-Консультант**: Нейросетевой ассистент Gemini AI, обученный на каталоге сайта, выслушает пожелание на естественном языке (например, "Хочу нежный свадебный комплект с теплыми бежевыми или персиковыми тонами и золотой фурнитурой") и автоматически укомплектует все детали согласно регламенту расхода.
6. **Чек-лист пошива**: Клиент в реальном времени видит детальный список покупок: сколько тканей, каркасов, резинок добавлено и что еще необходимо выбрать для полноценного пошива.
7. **Завершение**: Пользователь в один клик добавляет сбалансированный кастомный набор в корзину `subtelnedetale.pl`.

## 2. Архитектура интеграции в Laravel & Python (Backend)

Так как ваш основной сайт работает на связке **Laravel + Python**, интегрировать данный интерактивный модуль можно следующими тремя путями:

### Способ А: Встраивание собранного React-приложения (SPA) в блейд-шаблон (Самый надежный)
Vite компилирует всё приложение в оптимизированные файлы `dist/assets/index-[hash].js` и `dist/assets/index-[hash].css`.
1. Скопируйте содержимое сборки во фреймворк Laravel в папку public (`public/constructor/`).
2. Создайте роут в Laravel `Route::view('/constructor', 'constructor');`.
3. В Laravel Blade-файле подключите JS и CSS скрипты:
```html
@extends('layouts.app')
@section('content')
<div id="root"></div>
<script type="module" src="/constructor/assets/index-hash.js"></script>
<link rel="stylesheet" href="/constructor/assets/index-hash.css">
@endsection
```

### Способ Б: Прямой перенос в монолит (Laravel + Alpine.js / Tailwind)
Если вы хотите избежать React:
* Используйте разработанный нами интерактивный **SVG-чертеж бюстгальтера** (прямо из исходного кода `/src/App.tsx`). Весь SVG структурирован по `<g id="bra-cups">`, `<g id="bra-straps">`.
* С помощью Alpine.js свяжите динамические свойства цвета `fill` и `stroke` с выбранными цветами товаров из вашей базы данных MySQL.

### Способ В: Веб-компонент (Web Component)
Вы можете скомпилировать React-приложение как Custom Element (`<subtelne-constructor></subtelne-constructor>`) и подключать его в любую CMS без конфликтов с глобальными стилями и скриптами.

## 3. Проектирование Базы Данных (Laravel Eloquent / MySQL)

Для корректной работы каталога в конструкторе в таблицу продуктов (`products`) рекомендуется добавить следующие поля:

```sql
ALTER TABLE products 
ADD COLUMN is_constructor_compatible BOOLEAN DEFAULT FALSE, -- доступно в конструкторе
ADD COLUMN category_constructor_assigned VARCHAR(50), -- fabric, elastic, hardware, closure
ADD COLUMN color_hex VARCHAR(7) DEFAULT '#d1d5db', -- точный цвет для визуализатора
ADD COLUMN consumption_unit VARCHAR(10) DEFAULT 'm', -- м, комплект, шт
ADD COLUMN standard_consumption_qty DECIMAL(5,2) DEFAULT 1.0; -- норма расхода под 1 бюстгалтер
```

### Связки и Классификация деталей
| ID детали (`BraPartId`) | Описание пошивной роли | Категория сырья | Ожидаемые сопоставления в БД |
|---|---|---|---|
| **cups** | Чашки | `fabric` | Кружево эластичное, сеточка, микрофибра |
| **gore** | Перемычка / Мостик | `fabric` | Стабильная неэластичная сетка |
| **wings** | Пояс спинки | `fabric` | Эластичная функциональная сетка |
| **straps** | Бретели | `elastic` | Бретельные ленты подходящего размера |
| **elastics** | Резинки обшивные | `elastic` | Резинки с фестоном (верхний и нижний срезы) |
| **underwires** | Каркасы и Чехлы | `elastic` | Тоннельная лента + Пара металлических дуг каркасов |
| **hardware** | Фурнитура регуляторов | `hardware` | Комплект колец и регуляторов в цвет |
| **closure**| Застежка крючки-петли | `closure` | Одинарная/двойная застежка спинки |

## 4. Спецификация API (Laravel Endpoints)

Для обеспечения связки интерфейса конструктора с корзиной и базой товаров `subtelnedetale.pl` необходимо развернуть 3 основных эндпоинта:

### 1. Получить активный каталог товаров для конструктора
* **URL:** `/api/constructor/materials`
* **Метод:** `GET`
* **Ответ:**
```json
[
  {
    "id": "fab-lace-emerald",
    "name": "Koronka elastyczna 'Szantili' (Szmaragd)",
    "category": "fabric",
    "colorName": "Szmaragdowy",
    "colorHex": "#047857",
    "price": 38.00,
    "unit": "m",
    "description": "Premium koronka rzęskowa o szerokości 18 cm do szycia ekskluzywnych miseczek.",
    "standard_qty": 1.50
  }
]
```

### 2. Добавление кастомного набора в корзину (Laravel Session / Cart DB)
Позволяет в один клик перенести весь собранный набор деталей в системную корзину интернет-магазина.
* **URL:** `/api/constructor/cart/add`
* **Метод:** `POST`
* **Payload:**
```json
{
  "items": [
    {"product_id": "fab-lace-emerald", "quantity": 1.5},
    {"product_id": "elas-strap-emerald", "quantity": 1.2},
    {"product_id": "hard-set-gold", "quantity": 1.0}
  ]
}
```
* **Действие на Бэкенде:** Laravel перебирает массив `items`, проверяет наличие товаров на складе и добавляет их в стандартную корзину (`Cart::add`). Производится редирект на системную корзину.

### 3. Интеллектуальный помощник (Python / Gemini AI интеграция)
Если вы хотите переложить AI-рекомендации на ваш python-микросервис:
* Используйте готовую официальную библиотеку от Google `@google/genai` (Node.js) или `google-genai` для Python.
* **Промпт-инструкция** ИИ должна жестко ограничивать выдачу списком доступных ID товаров из вашей базы данных, чтобы предотвратить галлюцинации несуществующих артикулов.

## 6. Рекомендации по дизайну в стиле 'Subtelne Detale'

Чтобы интерфейс конструктора смотрелся гармонично с вашим польским бутиком `subtelnedetale.pl`:
* **Цветовая гамма**: Мы использовали благородный пудрово-молочный фон (`#fdfcf9`), элегантные теплые переливы высушенного золота (`#cca374`, `#aa8055`) и темные графитовые шрифты. Это подчеркивает премиальность и изящество.
* **Шрифтовые пары**: Рекомендуется использовать заголовочный антиквенный шрифт **Playfair Display** для брендинга и элегантный **Inter** для технических спецификаций, кнопок и цен.
* **SVG Чертеж**: Позиционирован по центру экрана на матовой полупрозрачной поверхности во избежание визуального шума. Все элементы интерактивны и имеют плавные hover-эффекты обратной связи.
